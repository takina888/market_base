LINEでも使えます

友だち追加、公式アカウント、グループ招待など、LINEで発行したリンクをQRコードにできます。作成したQR画像は共有ボタンからLINEへ送れます。

JAN・UPCはチェック数字を省略して入力できます。Code128は設備番号や部品番号などに向いています。
