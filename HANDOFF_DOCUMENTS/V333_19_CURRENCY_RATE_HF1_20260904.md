# MARKET BASE V333.19 為替換算レート安定化 HF1 引き継ぎ

作成日: 2026-09-04
基準: `MARKET_BASE_V333_19_FULL_HANDOFF_AND_DATA_20260810(2).zip`
対象: `market-base-currency-converter-v273-r29.html`

## 1. 方針

V333.19 の Android インストール安定化、ラジオ、キャッシュ更新、ページ遷移等の既存修正を触らず、為替換算ページだけを最小範囲で修正する。

グローバル build ID / `version.txt` / `sw.js` は変更しない。正式表示は V333.19 のまま。

## 2. 確認できた不具合

### A. 6時間以内の保存レートがあるとネットワーク確認を完全に省略

旧 `getRates(false)` は、`mb_rates_<BASE>` が6時間以内ならその保存値を表示して return していた。
そのためページを開いた時点で通信可能でも、より新しいレートを確認しないケースがあった。

### B. 長時間バックグラウンド後の再開時にレートを再確認しない

旧実装は初回ロード時の `getRates()` のみで、`pageshow` / `focus` / `visibilitychange` による再確認がなかった。
PWAを長時間残したまま再利用すると、古い表示のまま使い続ける可能性があった。

### C. 基準通貨を素早く切り替えると旧リクエストが新しい画面を上書きできる

旧 `selectBase()` はローカル換算値を作れる場合、新基準通貨のAPI取得を実行しない。
一方、切替前のAPIリクエストはキャンセルされないため、遅れて返った旧基準通貨のレスポンスが現在の `rates` を上書きできた。
これは「計算レートが大きく異なる」状態を作る重大要因。

### D. 更新表示がレートの基準日と取得時刻を区別していない

旧画面には初期状態で `2026/07/16 11:54` が固定表示され、API取得後も `Date.now()` を「最終更新」として表示していた。
APIが返したレート基準日と、端末が取得した日時を分けて表示する必要がある。

## 3. HF1 の修正内容

- 保存レートが新しくても、ページ開始時にオンラインの最新値を確認する。
- 取得中は保存値または内蔵参考値を暫定表示し、取得完了後に置換する。
- APIリクエストにシリアル番号と `AbortController` を追加し、旧基準通貨・旧表示通貨構成のレスポンスを破棄する。
- 基準通貨変更時はローカル換算で即時表示しつつ、必ず新基準通貨をオンラインで再検証する。
- `pageshow` / `focus` / 可視状態への復帰で、15分以上経過していれば再取得する。
- ページを開いたままでも15分ごとに再確認する。
- API要求にキャッシュバスターと `cache: no-store` を使用する。
- 9秒タイムアウトを追加する。
- 表示を以下に分離する。
  - `最新取得` — APIレート日 + 端末取得日時
  - `保存レート` — 保存されたレート日 + 保存取得日時
  - `内蔵参考レート` — 内蔵データの日付
  - 更新失敗時は `オンライン更新失敗` を追記
- 画面初期の固定 `2026/07/16 11:54` 表示を撤去し、`最新レートを確認しています` に変更。

## 4. レートソースの性格

現在の Frankfurter v2 は中央銀行等の公表値を集約した「最新の参照レート」であり、秒単位のリアルタイム市場価格ではない。
そのため Google、銀行の店頭レート、カード決済レート、FX取引レートと最終桁まで一致することは保証されない。
HF1 では誤解を避けるため、APIのレート日を画面上で明示する。

## 5. 再現・テスト結果

### 旧 V333.19 で再現

1. 6時間以内の保存レートを入れた状態では API 呼び出し 0 件となることを確認。
2. JPYのAPI応答を遅延させ、直後にTWDへ切替すると、旧JPY応答が後から反映され、TWD画面のUSD換算が大きく誤る状態を再現。

### HF1

Playwright のモックAPI試験で以下を PASS。

1. 新しい保存キャッシュが存在してもネットワーク取得を行い、オンライン値に更新する。
2. 旧基準通貨の遅延レスポンスが新基準通貨を上書きしない。
3. 16分経過後の focus で自動再取得する。

加えて、ページ内インライン JavaScript を `node --check` で構文確認済み。

## 6. 配布方法

最小上書きは次の1ファイルのみ。

`market-base-currency-converter-v273-r29.html`

`version.txt`、`sw.js`、Android/PWAインストール関連、ラジオ関連は変更しない。

公開先へ上書き後、オンライン状態で MARKET BASE の「更新」を1回実行する。
V333.19 の既存手動更新処理は、更新時にドキュメントをネットワークから強制再取得し、`mb_rates_*` の保存レートも消去するため、同一V333.19内のこのHTML修正を取り込める。

## 7. 実機での最終確認項目

- iPhone PWAを数時間バックグラウンドに置いた後、為替ページ復帰時に「更新確認中」→「最新取得」へ変わること。
- JPY / TWD / USD を素早く連続で基準通貨にしても換算値が飛ばないこと。
- 更新ボタン直後にレート日と取得日時が表示されること。
- オフライン時は保存レートまたは内蔵参考レートであることが明示されること。
- オンライン復帰後に最新取得へ戻ること。
