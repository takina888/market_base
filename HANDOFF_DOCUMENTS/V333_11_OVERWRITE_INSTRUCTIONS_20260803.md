# V333.11 上書き手順

## 基準

現在公開中のV333.8へ、V333.11上書きZIPの内容をそのまま上書きする。V333.9、V333.10を先に適用する必要はない。

## 手順

1. `MARKET_BASE_V333_11_OVERWRITE_FROM_V333_8_20260803.zip`を展開する。
2. 展開されたフォルダ構造を保ったまま、GitHubのMARKET BASE公開フォルダへ上書きする。
3. GitHub Pagesの公開処理完了を待つ。
4. MARKET BASEを開き、更新ボタンを1回押す。
5. 「学ぶ」からUL・CEガイドを開き、「質問から探す」を確認する。
6. 最初に8問だけが表示され、仕事の段階と専門Q&A全件へ切り替えられることを確認する。

旧ファイルを一括削除する必要はない。上書きZIPに含まれるファイルだけを置き換える。
