# V333.10 上書き手順

## 基準

現在公開中のV333.8へ、V333.10上書きZIPの内容をそのまま上書きする。V333.9を先に適用する必要はない。

## 手順

1. V333.10上書きZIPを展開する。
2. 展開されたディレクトリ構造を保ったまま、GitHubのMARKET BASE公開フォルダへ上書きする。
3. GitHub Pagesの公開処理完了を待つ。
4. MARKET BASEを開き、更新ボタンを1回押す。
5. スマートフォンとPCでトップ、DB、読み物など複数ページを開く。
6. Cloudflare Web Analyticsでアクセス記録を確認する。

旧ファイルを一括削除してから入れ直す必要はない。上書きZIPに含まれるファイルだけを置き換える。
