# MARKET BASE V333.19 為替換算 HF3 — 市場レート化

作成日: 2026-09-07
Build: `MARKET_BASE_V333_19_JFM_V077_CURRENCY_HF3_20260907`

## 原因
HF2 までのオンライン主系統は Frankfurter v2 でした。Frankfurter は中央銀行・公的機関の参照レートを集約するサービスで、最新値は提供元の公表タイミングに依存し、日中の市場急変を即時反映する用途には向きません。そのため、ユーザーが「更新」を行っても、数時間前の大きな市場変動が表示値に反映されないケースが発生しました。

## HF3 の変更
1. 主系統を `fxapi.app` に変更。全選択通貨を1回のリクエストで取得し、約5分更新の市場レートとして扱う。
2. 主系統失敗時は `currencyexchangetool.com` の CORS 対応ライブペア API を第2市場系統として使用。
3. 両市場系統が失敗した場合のみ Frankfurter を日次参照レートとして使用。
4. Frankfurter 値を「市場レート」「最新市場値」と誤表示しない。
5. 画面上で `市場レート / 保存市場レート / 日次参照レート / 保存参照レート / 内蔵参考レート` を明確に区別。
6. 市場データの時刻と端末取得時刻を分離表示。
7. 自動再取得間隔を15分から5分へ変更。手動更新は即時再取得。
8. HF2以前の `mb_rates_<BASE>` キャッシュは旧Frankfurter保存値として認識し、`保存参照レート` として扱う。
9. HF3 市場系キャッシュは `mb_rates_hf3_<BASE>` に分離し、旧参照値との混同を防止。
10. 基準通貨切替・並べ替え・入力中フォーカス維持・競合防止はHF2の安全策を維持。

## 取得優先順位
1. fxapi.app — 市場レート、約5分更新
2. Currency Exchange Tool — 市場レート、Yahoo Finance系ライブデータ
3. Frankfurter — 日次・公的参照レート
4. 保存キャッシュ
5. 内蔵参考レート

## 重要
為替換算値は中間市場レートの参考値です。銀行・カード会社・両替所のスプレッド、手数料、決済時点のレートは含みません。
