# 日本語版JSON 引き渡し一式

このフォルダーは、v040 Excelの日本語5シートをV333.19のデータ構造へ安全に変換した引き渡し用一式です。

## 内容

- `data/japan_food_machinery_db_v075.json`：互換マージ済みJSON
- `data/japan_food_machinery_db_v075.js`：同内容のオフライン用JSミラー
- `embedded-cross-db-search-index-v273-db-title-r27.js`：JFM 2,719件、全体5,175件の検索索引
- `embedded-cross-db-search-summary-v333-16.js`：更新済み検索summary
- `VALIDATION_REPORT_JA.md`：検証結果と本番組込時の必須対応
- `scripts/`：再生成・検証用スクリプト

最終件数は191社・2,528製品です。旧製品ID485件をすべて保持し、同一性を確認した25件は新行へ旧IDを移管、旧版だけの別製品30件と旧版だけの会社24社も保持しています。

公開用データから、`輸出情報調査注記`191社分、重複する旧DB判断メモ、トップレベルの自由文`notes`を削除しました。仕様・出典・海外展開の根拠など有用な情報は捨てず、公開向けの自然文へ移しています。旧型式25件の補足も「関連型式・名称」「処理能力」「外形寸法」などの表現に整えています。

## 重要

これは安全なデータ引き渡し一式であり、4ファイルだけを現行サイトへ上書きして公開するための完成リリースではありません。HTML表示項目、固定件数、キャッシュ世代、オフラインmanifest、プレビュー候補、回帰テストも連動更新してください。公開画面の「調査上の注記」行は、削除済みフィールドを参照しないよう同時に外してください。詳細は `VALIDATION_REPORT_JA.md` を参照してください。

元のZIPとExcelには変更を加えていません。
