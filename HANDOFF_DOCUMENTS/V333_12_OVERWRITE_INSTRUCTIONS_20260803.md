# V333.12 上書き手順

## 基準

現在公開中のV333.8へ、V333.12上書きZIPの内容をそのまま上書きする。V333.9〜V333.11を先に適用する必要はない。

## 手順

1. `MARKET_BASE_V333_12_OVERWRITE_FROM_V333_8_20260803.zip`を展開する。
2. フォルダ構造を保ったまま、GitHubのMARKET BASE公開フォルダへ上書きする。
3. GitHub Pagesの公開処理完了を待つ。
4. MARKET BASEを開き、更新ボタンを1回押す。
5. 「学ぶ」→「UL・CE規格」→「質問から探す」を開く。
6. 最初の質問を開き、「背景と仕組み」「具体例」「よくある誤解」「確認手順」が表示されることを確認する。

旧ファイルの一括削除は不要。上書きZIPに含まれるファイルだけを置き換える。
