MARKET BASE V333.19 Android版 インストール手順

対象APK:
MARKET_BASE_V333_19_ANDROID_API36_RELEASE_20260810.apk

1. Samsung InternetでMARKET BASEを開きます。
2. 表示される案内から「公式Android版をダウンロード（推奨）」を押します。
3. ダウンロード完了後、APKを開きます。
4. 「この提供元を許可」または「不明なアプリをインストール」と表示された場合は、
   「設定」→「Samsung Internet」→「この提供元を許可」をオンにします。
   繁體中文表示では「允許此來源」です。
5. 前の画面へ戻り、「インストール」を押します。
6. インストール後は「この提供元を許可」をオフへ戻して構いません。

Google Play Protectは無効にしないでください。
このAPKはAndroid API 36を対象にし、MARKET BASEのリリース証明書で署名されています。
直接配布APKのため、端末の通常の安全確認や「この提供元を許可」は表示されることがあります。
