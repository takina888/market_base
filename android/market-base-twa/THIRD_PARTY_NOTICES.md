# Third-party components

This project depends on:

- `com.google.androidbrowserhelper:androidbrowserhelper:2.6.2`, Apache License 2.0.
- AndroidX libraries pulled transitively by Android Browser Helper.
- Gradle Wrapper 8.11.1.

The project layout and launcher configuration follow the public Bubblewrap / Android Browser
Helper guidance. No dependency source code, signing key, or user credential is stored here.

References:

- https://developer.chrome.com/docs/android/trusted-web-activity/
- https://github.com/GoogleChrome/android-browser-helper
- https://github.com/GoogleChromeLabs/bubblewrap
